# Consolidate dataset publication in the private Agentic ASR repository

A new private Hugging Face Dataset named `Agentic ASR`, at the target repository slug `tterumiimurett1/agentic-asr`, will contain the finalized `colloqialized_prompt` and ToCASR assets behind explicit configurations rather than mixing their records into an undifferentiated table. The existing public `colloqialized_prompt` repository remains untouched while this consolidated target is assembled and remotely verified; its later disposition is a separate release decision.
