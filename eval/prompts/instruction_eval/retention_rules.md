CALIBRATED RETENTION RULES (override earlier conflicting instructions):
- Measure preservation of expressed intent, not whether the original task is executable without its environment. A missing operational detail in the REFERENCE is not a candidate omission. References to the current document, recent messages, or an external requirements file can be retained without inventing their details.
- Each action gate is 0 or 1 (null only if genuinely unresolved before adjudication). Wrong parameters do not close an otherwise retained action gate.
- Atom values are normally 0 or 1. The ONLY 0.5 case is omission of an originally vague qualifier. For that case include "loss_type":"vague_qualifier_omitted" and a reason identifying the vague reference qualifier and its omission. "Recent messages" -> "messages": time atom=0.5. "Past seven days" -> no time limit: time atom=0. "Recent" -> "past seven days": reasonable concretization, time atom=1. Clear conflicts or reverse requirements score0 on their own dimension. Do not use0.5 as uncertainty, confidence, or a generic partial-credit value. Do not generalize this permission to arbitrary added constraints.
- Omission scoring must use the complete candidate text. Partial credit never deletes an atom. 0.5 affects recursive averaging only; it does not block dependent actions. Do not calculate propagation yourself.
- If the candidate preserves the reference's own contradiction, the relevant atoms score1. Example: both say "past ten years, meaning2013–2019". Record an optional diagnostic note; do not flag unresolved retention merely because the original is contradictory. Do not silently repair the original. A NEW candidate contradiction is different and does not count as preservation merely because reference words are present. If the candidate changes one side of a reference contradiction and the rules do not resolve it, state that specific unresolved question rather than inventing a policy.
- Resolve explicit relationships across the full text. "Files are in /tmp_workspace/: calendar.ics" retains /tmp_workspace/calendar.ics. Directory plus filename/list is equivalent to a contiguous path; whitespace, prose vs lists, and lack of repeated full paths are not losses. Do not guess an ambiguous directory association or fix an actually wrong identifier.
- For URLs that must be accessed, host/domain case is irrelevant. Compare paths strictly, including case, characters and hierarchy. /videos/A.mp4 differs from /video/A.mp4 and /videos/a.mp4. Never lowercase a whole URL. Unambiguous oral spelling can express the same literal URL; apply the SAME identity standard after decoding oral spelling and to formatted URLs. Do not repair missing letters or changed paths using knowledge of the intended URL. These rules do not newly define equivalence for query/fragment/encoding.
- diagnostic_notes are nonblocking observations, distinct from review_reasons. Use review_reasons only for genuine unresolved representation or retention, and identify the specific problem. In Forward, genuinely unresolved nodes must have value=null; do not put a definite value and then express uncertainty about that same verdict. A single targeted adjudication will handle unresolved items. Do not request human review or invent missing requirements.
